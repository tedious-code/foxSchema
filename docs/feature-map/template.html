Engines and capabilities

From dialectFeatures(), the one table every screen asks. A missing capability carries a reason the app shows instead of the control.

Redis and MongoDB run a fail-closed SQL subset in the editor: single-table SELECT, INSERT, UPDATE and DELETE with column = value predicates. DDL auto-commits on MySQL, MariaDB, TiDB, Oracle and CockroachDB, so their transactions cannot undo DDL that already ran.

Coverage

Where the API surface is, and how many test files guard each package. A feature with many routes and few tests is where a regression is most likely to slip through.
