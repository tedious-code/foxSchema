# Release notes

Per-version ship notes. Each file is the body of a GitHub Release
(`gh release create --notes-file`), written at the time that version shipped.

These are **history**. They describe the tree as it was on their release date
and are not maintained afterwards — a path or a command in one of these files
may well not exist any more. Nothing here is a map of the current code; for
that, start at [`docs/CODE_MAP.md`](../CODE_MAP.md).

They live in their own directory because twelve of them had accumulated in
`docs/`, where they outnumbered the documents people actually need to find.

Every version on one page: [SUMMARY.md](SUMMARY.md).
